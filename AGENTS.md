# SubKill — для агентов

Отвечай пользователю по-русски.

Перед работой прочитай `docs/STATUS.md` и `docs/DECISIONS.md`.
После работы обнови `docs/STATUS.md`. Если принял решение — допиши `docs/DECISIONS.md`.

Карта кода: `docs/ARCHITECTURE.md`.

## Продукт

Находим лишние подписки в почте и помогаем их отменить.

v1 — этот Vite/React (порт 5174). Flutter не переписывать. SMS не трогать.

## Нельзя

- Переоткрывать решения из `docs/DECISIONS.md`, пока пользователь явно не попросил.
- Править файлы, которые в `docs/STATUS.md` уже заняты другим чатом. Остановись и скажи об этом.
- Менять Gmail-доступ шире, чем чтение (`gmail.readonly`), или обещать вход любому аккаунту, пока Google не проверил приложение. Client ID уже есть в `.env`.
- Выдумывать отмену через «отправь письмо», если биллинг Apple / Play / PayPal.
