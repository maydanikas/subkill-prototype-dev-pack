# SubKill

Я собираю продукт в этом репо. React — клиент v1. Flutter не переписываю, пока флоу не живой.

```bash
npm install
npm run dev
```

## Что уже кликается

1. Онбординг → «Подключить Gmail» (живой ящик) или «Сначала демо»
2. Скан в 3 прохода
3. Дашборд: годовая сумма, red pills (score ≥ 70), pie с живых категорий
4. Список со Waste Score и причиной: забытая / дорого / дубликат / триал-ловушка
5. Фильтры: Все / Забытые / Дорогие / Дубликаты
6. Убийство: прямая ссылка / AI-письмо / инструкция Apple·Play
7. 3 бесплатные отмены: в демо — лист «подключи Gmail»; в живом Gmail — paywall $2.99/мес или $19.99/год

## Пока мок

Paywall Pro не берёт деньги и не запоминается. Демо-ящик — `src/fixtures/mailbox.ts`. Живой Gmail уже подключён ключом в `.env`; чужие аккаунты Google пускает только после своей проверки (restricted scope).

Верификация Google на restricted scope. Без неё в Play нет настоящего сканера.
